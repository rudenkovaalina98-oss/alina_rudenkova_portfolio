Onboarding automation suite

Nine automations that took a cohort's admin work from a full day and more to under an hour.

Problem

  • Candidate data copied by hand from the ATS into several sheets
  • Separate spreadsheets per audience, duplicates, inconsistent formats
  • Accounts, welcome emails and access requests handled one by one

Result

  • Manual work per cohort: up to 15 h → ~40 min
  • Fewer copy-paste errors and one place to look up a newcomer
  • Each automation logged in the company's Ops AI tools database

AI chat simulations: from one bot to a multi-scenario trainer

I led the move from a single Zapier simulation to a flexible HTML + Gemini API format that could hold many client personas. The idea and groundwork were later built into the new platform as a multi-scenario training tool.

Problem

  • One existing Zapier simulation was hard to embed in the LMS
  • It couldn't scale to many personas for different training goals

What I built

  • Interim step: HTML pages with embedded Zapier chatbots
  • Main format: HTML chat on the Gemini API via a Cloudflare Worker proxy
  • Client personas by behaviour type (sceptic, impatient, aggressive, meaning-seeker…)
  • 5-criteria scoring rubric and a separate evaluator prompt
  • Guardrails: anti-role-reversal, attribution rules, hidden compliance scenarios
  • Apps Script export of results to the tracker with pass/fail flags
  • API comparison (Gemini, GPT, Claude, Zapier) and a write-up of data/legal risks

Result

  • Built into the new platform as a multi-scenario training tool
  • 10 practice and scored sessions per chat type
  • Passing the simulations is required to activate a specialist's profile

New onboarding platform: specs and prototypes

Requirements, clickable prototypes and process design for the platform that replaced spreadsheet tracking and four separate tools.

Problem

  • Onboarding ran across LMS, Zapier, Slack and email
  • Support questions lost in DMs; no single view of a newcomer
  • Every failed check needed a manual decision

What I built

  • Dev specs: operations and analytics dashboards (onboarding score, pass rate, time-to-activation, on-time rate, satisfaction)
  • Notification system and registration/login flow
  • Manual bug-reporting and escalation process for the onboarding stage
  • Clickable HTML prototypes and Figma process diagrams to align with developers
  • Built-in support chat on the platform with automated reminders instead of Slack/email
  • Automated readiness-check rules

Result

  • 4 tools consolidated into one platform
  • Only borderline cases go to manual review
  • Developers worked from prototypes, not guesses
